# Literature map and claim-to-source ledger

Cutoff: **2026-09-02**. This is a bounded primary-source review, not a guarantee that no concurrent work exists. Venue labels below distinguish peer-reviewed publications from preprints and workshop papers. Reported numbers belong to the cited papers and have not been reproduced in this repository.

## Reproducibility warnings discovered during source audit

- PONR: dataset is released, but a matching code repository was not located; published scale descriptions contain ambiguities.
- Soft-target pre-generation probing: the public source-code placeholder was not resolvable, and model naming is inconsistent.
- Chameleon: paper/code/public-output counts and regression features do not fully reconcile; public scripts use row-random splitting and have reproducibility defects. Pin and independently audit before reuse.
- Genadi et al.: public implementation appears to include the target assistant answer and row-random question variants; do not describe it as pre-response prediction.
- PAVE: distinguish preprint/data availability from its reportedly withdrawn ACL Findings acceptance.
- BASIL and Truth or Dare: no stable official code/data repository was found at cutoff.
- DeReLab appeared immediately before the cutoff; its appraisal prompt is order-sensitive, so appraisal-first is not a transparent latent-state readout and needs counterbalancing.
- SyRoUP repository notes that the ACL version, not an earlier arXiv result, is authoritative.

These caveats do not negate the papers’ ideas. They determine what can be treated as verified method, reusable artifact, or merely a reported result.
